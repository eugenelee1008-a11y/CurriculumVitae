# Eugene Lee — academic website (GitHub Pages)

This package contains an academic website and a PDF CV. It uses only HTML/CSS and can be hosted for free on GitHub Pages.

## Before publishing

1. Open `index.html` and review the three provisional dissertation titles; there are no required personal-information placeholders remaining.
2. Open and edit `Eugene_Lee_Academic_CV.docx` (provided separately). Export an updated PDF as `Eugene_Lee_Academic_CV.pdf` and replace the PDF in this folder.
3. Confirm your three dissertation *working titles* before publishing.
4. The research and teaching statements in this package are your supplied, unchanged PDFs. Review these before publishing.
5. Optional: add your code/project links.

## Publish with GitHub Pages

1. Sign into GitHub (your Google/Gmail-based login is fine).
2. Create a public repository named `<your-github-username>.github.io`.
3. Upload the **contents** of this folder (especially `index.html` and the PDF) into the repository root.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then Save.
5. Your site will become accessible at `https://<your-github-username>.github.io/` once deployment is complete.

You may instead host this content as a project site inside a differently named public repository; the URL then normally includes the repository name.

Note: This package does NOT publish to your GitHub account automatically. It has no backend, database, tracking code, or subscription.
